# GlassBoard Enhanced · 桌面整理修改版

基于 GlassBoard v0.9.17 用户包的个人修改版，适用于 Windows 10/11。**baijiang-441 是本修改版维护者，不是 GlassBoard 原始作者。** 原作者身份尚未核实，已知包来源及第三方署名见 [来源与署名](ATTRIBUTION.md)。

本仓库汇总 2026-10-30 至 2026-10-31 的本地新增和修复，保留对应源码、便携程序、回归检查和构建说明。当前版本 **v0.9.17-enhanced.2**，完整变更见 [更新记录](CHANGELOG.md)。

## 本次修改

- 文件及真实文件夹改名同步磁盘、内部路径、Dock 与工作区；保存失败尝试回滚。
- 新建、改名、删除分组；拖动分组排序；默认分组可更名、移动、隐藏及恢复；删除分组保留磁盘文件。
- 图标手动拖动排序，长按选择、空白拖动框选、跨页多选、批量移动和移除入口；单击空白清除选中。
- “全部”收录用户桌面和公共桌面可见顶层项目及此电脑、回收站；每 10 秒检查新增内容。
- 主页“自动整理”：按类型和名称排序，支持全量/当前分组；支持 Ctrl+Z 撤销和后续手动拖动。
- 滚轮向下/向上翻页；首末页不循环，滑块、输入框和菜单操作不被截获。
- 真实文件默认使用 Windows Shell 经典右键菜单，含系统及第三方扩展；GlassBoard 管理菜单保留独立入口。
- Dock 运行中应用右键读取应用已有的快捷任务，提供正常关闭窗口/全部窗口、确认后结束后台进程及任务管理器。
- Dock 默认直接展示所有运行应用；设置长度，图标过多时重叠，悬停时相邻图标让位；再次点击前台应用可最小化，点击最小化应用可恢复。
- 悬停查看 DWM 窗口缩略图、多窗口与可读取的标签页；不点击时保持原最小化状态。预览采用任务栏风格外框和标题、关闭按钮。
- 应用面板入口悬停临时预览，移出后收起，点击固定；默认贴近 Dock 上方 8 个逻辑像素。后台读取图标和缓存布局，减少展开时的等待。
- Dock 最右侧新增原创性能曲线图标，一键打开任务管理器，常用和运行模式均可用。
- 修复批量操作和对话框期间窗口重排导致的闪烁；底边仅 Dock 所在横向区域可唤出；鼠标留在图标上时检测并修复外部窗口遮挡。
- 保留 Windows 原任务栏；隐藏任务栏是可选设置。移除本修改版中的赞助和宣传界面，停用上游更新以免覆盖修改。

## 直接使用

下载仓库或 Release 完整便携包，运行 `portable/Start.cmd` 或 `portable/GlassBoard.exe`。请保留旁边的 DLL、lib 和 data 目录。

配置保存在当前 Windows 用户的 `%LOCALAPPDATA%\GlassBoard`，**不在仓库中**。运行前请退出其他 GlassBoard 版本；切换版本前备份整个配置目录。此包不包含维护者的桌面路径、个人分组、使用记录或账号信息。

## 构建与检查

需要 Windows、支持 C# 11 的 .NET SDK，以及 .NET Framework 4.8 目标包/开发工具。

```powershell
.\Build.ps1
.\Build.ps1 -Test
```

脚本先构建 `source/GlassBoard.csproj`，更新 `portable/GlassBoard.exe`，再按需构建并运行隔离测试。测试数据写入系统临时目录，不使用用户实际 GlassBoard 配置。

本机最新完整回归 **179 项通过**，详见 [验证记录](docs/VALIDATION.md)。其中联想应用任务检查仅在本机对应缓存存在时执行，其他电脑检查数量可能不同。

## 使用边界

- 这是非官方修改版，未承诺兼容上游后续版本；程序集版本仍为 0.9.17.0，以本仓库标签区分修改版本。
- 系统文件菜单是 Windows Shell **经典菜单**；Dock 应用任务菜单由本程序显示已有任务数据，不等同于 Windows 11 任务栏菜单宿主。
- 应用任务按程序路径匹配；未提供可读取任务或使用不同辅助程序的项目可能不显示。菜单不会自动执行更新或卸载任务。
- 关闭窗口发送正常关闭请求，允许应用提示保存，不强制终止进程；高权限窗口可能拒绝请求。
- 桌面收录不递归、不收录隐藏/系统属性文件；不自动清除已移走项目的旧入口。已有完整导入后手动移除的入口不会被下一轮强制加回。
- 缩略图由 Windows DWM 提供，外框由本程序绘制，不是系统任务栏弹窗宿主。标签页选择依赖应用暴露的 UIA 接口；最小化时使用已有缓存，未暴露标签页的软件只显示窗口预览。
- “结束后台进程”属于强制结束，可能丢失未保存内容，操作前弹窗确认；只按完整程序路径匹配当前会话实例。高权限程序可能拒绝结束。
- 第三方前台应用的所有窗口组合尚未逐一测试。
