# 离线分类表

编辑 AppGroups.tsv，保存为 UTF-8。每行三个字段，以 Tab 制表符分隔：
分组名称、匹配方式、别名列表。别名之间用 | 分隔。# 开头为注释。

word：词或名称匹配，自动统一大小写、空格、标点和全角字符。
exact：完整名称/启动文件名匹配，适合 PS、AE、PR 等短缩写。
长别名优先，避免 QQ音乐误判为 QQ 社交。分组名不能使用全部或未分组。

例如（下方使用实际制表符）：
创作	exact	PS|AE|PR
游戏	word	我的游戏中文名|My Game English Name|ActualGameExecutable
Mod工具	word	我的模组管理器|MyModManager

修改后在软件点击“自动分组”重新加载，只整理未分组项目。
你的手动分类偏好优先于文本表，不会被自动覆盖。

本版包含 1,173 条去重的分组/模式/别名规则，并不等于 1,173 款不同软件。
新增网盘下载、安全维护、学习阅读、金融财务等分类，兼顾中文名称和明确的启动文件名。
品牌中的短词不会泛化匹配，如 QQ音乐、QQ浏览器优先匹配对应完整名称。
